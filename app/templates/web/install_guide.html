把公告助手加入主畫面

從圖示直接開啟公告與待辦。安裝不會自動開啟通知，截止提醒需要逐筆自行確認。

請先用 Safari 開啟本網站，再依下列步驟操作。

  1. 在 Safari 點「分享」。
  2. 選「加入主畫面」。
  3. 確認名稱並點「新增」。
  4. 回主畫面，從新圖示開啟公告助手。

iPhone／iPad 的裝置推播需要 iOS／iPadOS 16.4 以上及主畫面 App，還要由你同意通知。

Safari 分頁與主畫面 App 的待辦可能分開保存。若沒有看到原待辦，請從公告重新加入；不會自動上傳或搬移資料。

開啟瀏覽器選單，尋找「安裝應用程式」或「加入主畫面」。選項依瀏覽器而異，未提供時仍可正常使用網站。
